Everything here is simulated and computed on your device. Move the sliders: inside its training range the network helps, outside it can make things worse.

How to read this

  • Single slots vary. One slot can flatter or embarrass either estimator. That is why the number at the top is a mean over many slots, as in the project's results.
  • This is not the speed of a receiver. One slot takes a few milliseconds here, simulation included, in plain JavaScript. The same network in C++ takes about 0.085 ms on a laptop.
  • The network gets the exact SNR. A real receiver would have to estimate it. The simulation uses QPSK and is one simple channel model, not a measured channel.
  • Nothing leaves your device. There is no server behind this page, and it sets no cookies. The network runs in about 100 lines of JavaScript, which match ONNX Runtime bit for bit.
